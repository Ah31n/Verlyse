# Verlyse Media — Route-by-Route Interaction Map

**Publication:** Verlyse Media  
**Scope:** Interactive Behaviors across all 53 Routes  
**Date:** October 2026  

---

## Route Interaction Ledger

| Route | Primary Action | Secondary Actions | Keyboard Triggers | Touch Gestures |
|---|---|---|---|---|
| `/` | `Enter the archive` (`/articles`) | Read Lead Feature, Department jumps, Enter Room | `Tab`, `Enter` on CTA, `Space` scroll | Vertical pan, tap cards |
| `/articles` | Filter by category pills | Search live query, save article to shelf | `Tab` across pills, `/` to focus search | Horizontal pill scroll, card taps |
| `/categories` | Enter Department Door | Jump to related room query | `Tab`, `Enter` on door | Vertical stack tap |
| `/categories/*` | Read Lead Story/Poem/Essay | Return to All Wings, Browse Shelf | `Tab`, `Enter` | Standard reading scroll |
| `/article/:id` | Read longform prose/poetry | Save to shelf, share article, return to wing | `Tab` to action buttons, `Esc` closes share dialog | Smooth vertical reading pan |
| `/creators` | Open Creator Dossier | Filter by category, view related works | `ArrowLeft`/`ArrowRight` on wall, `Enter` selects | Tap creator name/card |
| `/creator/:id` | Open creator's individual works | Return to contributor wall | `Tab`, `Enter` | Vertical scroll |
| `/submit` | Submit manuscript payload | File attach, word count check | `Tab` through form fields, `Enter` on submit | Touch inputs with 44px+ touch targets |
| `/contact` | Send correspondence | Copy direct email | `Tab`, `Enter` | Touch input |
| `/about` | Review colophon & principles | Explore founder monograph | `Tab` | Vertical reading |
| `/community` | Read reader reflections | Submit reflection | `Tab` | Vertical reading |
| `/ambassadors` | Apply for ambassadorship | View ambassador monographs | `Tab` | Vertical reading |
| `/room` | Pull & inspect folio (`Enter`) | Rotate arc (`←`/`→`), search (`/`), help (`?`), reset (`Esc`) | `←`, `→`, `Enter`, `Esc`, `/`, `?` | Horizontal drag orbit, bottom sheet swipe |
